# Agent teaching Method

* A teaching unit is considered a root branch in the overall_program.md program list.
* Each topic will have a directory called {order number}_{topic name}.
* Within each topic folder, there will be an intro.md file that includes a general description of the topic and its subtopics, the objective for the reader, the prerequisites, and a structured summary of the subtopics and a link to them. 
* A subtopic will have a subfolder with the same name as the subtopic inside its parent topic folder.
* Each subtopic folder will include a file called {order number}_{subtopic name}. This file will containt all the theory for the subtopic.
* Inside the subtopic folder there will be a file {order number}_{subtopic name}_exercises.md that contains the exercises for the subtopic. The exercises can be questions based on the theory learned as well as implementation exercises such as equations, code, etc. These exercises are meant to be solved by the reader.
* Inside the subtopic folder there will be a file {order number}_{subtopic name}_solutions.md that contains the solutions for the subtopic.
* The agent will not generate content for any topic or subtopic unless it has been explicitly requested.
