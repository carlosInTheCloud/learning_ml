# Part 1 — Mathematical Foundations

The prerequisites for everything that follows, covered only where a later part consumes them, and to full depth where it does.

This part is a refresher, not a mathematics degree. A result earns its place here by being used later: eigendecomposition because PCA and optimization landscapes need it, matrix calculus because backpropagation is unforgiving without it, maximum likelihood because four later parts are built on it. Results that nothing downstream uses are marked as extensions.

Nothing outside this part assumes mathematics that this part did not establish.
